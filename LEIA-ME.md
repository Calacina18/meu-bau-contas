# Meu Baú

Este é um site sem tela de login. As contas e a renda ficam no armazenamento local do navegador. Alterações feitas no computador não aparecem automaticamente no celular; use **Baixar backup** e **Importar backup** para transferi-las.

## Atenção antes de publicar

O GitHub Pages publica o site na internet. As faturas iniciais estão incluídas nos arquivos do site para aparecerem na primeira visita, então seus nomes, valores e vencimentos poderão ser vistos por qualquer pessoa que acessar o site ou os arquivos do repositório. Não publique esta versão sem aceitar essa exposição.

## GitHub Pages

A fonte do GitHub Pages é a raiz da branch `main`. Envie as alterações para essa branch para atualizar o site. O endereço aparece em **Settings → Pages**.

Se o repositório GitHub for público, os arquivos do site também poderão ser vistos e copiados. Mesmo com um repositório privado, o próprio site do GitHub Pages é público.

## Uso

- Marque a caixa da conta para indicar que foi paga.
- O botão **Nova conta** permite cadastrar vencimentos e parcelamentos mensais.
- O botão **Importar backup** restaura um arquivo JSON neste navegador e substitui as contas atuais.
- O botão **Baixar backup** exporta contas e renda para transferir ou guardar.

O vale-refeição é calculado separado do salário e só abate contas marcadas como refeição.
